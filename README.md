# LinuC 私有云端学习工作台

网站：https://wjaskon.github.io/linuc-study/

GitHub Pages 托管静态网页，Supabase 保存笔记、错题、截图和复习进度。使用邮箱登录链接登录；首次请使用 Supabase 组织成员的邮箱，因为默认免费邮件服务对收件人有限制。

## 保存行为

- 保存记录、导入资料、复习自评会直接提交云端，只有服务器确认后才显示成功。
- 新设备用相同邮箱登录后读取同一份资料。返回旧设备时可点击“刷新云端”。
- 版本检查防止旧设备静默覆盖新设备资料。冲突或网络失败时保留未保存草稿在页面内存，需导出未保存草稿再刷新重试；关闭页面会失去内存草稿。
- 浏览器仅持久保存登录会话；学习资料以云端为准。旧版本地资料仍保留，可在“备份与 AI 助手”手动迁移。
- 数据库启用 RLS，每个账号只能读取和写入自己的资料。公开连接配置不是管理员密钥，仓库中不得加入 service_role 或数据库密码。
- 每张截图最多 2 MB；当前单个学习资料文档最多约 25 MB（含图片编码），建议以文字为主，定期导出独立备份。
- 免费 Supabase 项目可能因低活跃暂停，需到控制台恢复。免费方案没有持续可用性保证。
- ChatGPT 整理和出题仍采用提示词复制和 JSON 导入，无收费 AI API。

`cloud-schema.sql` 为已经执行的初始数据库配置，不要在同一项目重复运行策略创建语句。项目数据库的真实密码不在仓库内。

发布：将 index.html、README.md、cloud-schema.sql 放到 main 分支根目录，GitHub Pages 发布 main / (root)。
